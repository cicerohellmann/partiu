# Build with: how to build each ticket

This map says which part of the KMPstarter base in `mobile/`, which pattern and which public sample app to copy for each concern in the tickets. Start from the base, copy patterns from the samples, add only what a row says is missing.
Sample apps are all by `joreilly` on GitHub (links are on `main`). "not in base" means the base has nothing: add it. "none" means no sample shows it: design it from the ticket.
Base = the KMPstarter base in `mobile/`; paths are relative to its root. Its `SOFTWARE_PATTERNS.md` rules (repository, state machine, adapter, use case, ViewModel) apply everywhere.
